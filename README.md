# CSS Full Course

A small HTML page and annotated stylesheet for studying CSS selectors and the cascade. The stylesheet shows how to target elements by type, class, ID, state, relationship, or attribute, and includes notes on specificity and color.

## View the examples

Open [index.html](CSS%20Full%20Course/index.html) in a browser and read [style.css](CSS%20Full%20Course/css/style.css) next to it. Use the browser inspector to see which rules match the page elements.
